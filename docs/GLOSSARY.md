# Glossary: code names and paper terms

The code predates the paper's terminology. Names in the code, run tags, and file names map to the paper as follows.

| In the code | In the paper |
|---|---|
| disclosure, `relied`, `RELIED ON` line, `rely_line` | self-attribution, attribution statement $t$ |
| `relied_src` (strict judge) | attribution that names the piece's source |
| influenced, consequential, pivotal | influential |
| hidden influence | omission |
| false disclosure | false attribution |
| adopt / `own` (LLM-judged) | $\mathrm{match}(a, s)$ |
| re-ask, closed-book, counterfactual sample | counterfactual answer (sampled with $s$ removed) |
| `k4` rule | Definition 1 with $N=4$, $L=1$, $U=3$ |
| `syco` | user suggestion |
| `x_tool`, `x_peer`, `x_meta`, `x_sys`, `x_cred` | tool output, another AI's answer, question metadata, system-prompt note, claimed expertise |
| `x_sysn` / `xc` | system-prompt note with neutral wording |
| channels | tool outputs and another AI's answers (training) |
| `val`, `val2` | validation set |
| `test` | test set |
| `test2`, `t2`, `t2x` | fresh set |
| `apiq2`, `api2-<model>` | large set |
| `api-<model>` | frontier models on the 105 questions with system-prompt notes |
| `cfdisc*` | CREDIT |
